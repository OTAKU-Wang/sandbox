## 3. 本轮已修（含证据与回归测试）

### 3.1 B1 — 证书登录缺服务端 challenge，客户端断言可无限重放
`POST /api/v1/auth/login/cert` 只校验客户端提交的 SM2 断言，无服务端 nonce/challenge：抓一次断言可无限重放登录。
新增 `app/core/challenge_store.py`（一次性 challenge、TTL、有界表 + 本地过期裁剪），`app/api/auth.py`
新增 `GET /auth/login/cert/challenge` 签发、登录时消费（单次使用，重复使用拒绝），`app/services/auth_service.py`
把 challenge 绑入断言校验。回归：`tests/test_pz10_mfa.py`（+91 行，覆盖未签发/重复消费/过期/绑定不匹配）。

### 3.2 B2 — 平台密钥调用的审计写入失败被静默吞掉
`app/core/deps.py` 的 `api_key.call` 审计是 `except Exception: rollback`，审计存储故障时机器调用整批从防篡改链消失。
改为 `cds_audit_write_failures_total{op}` 计数（`app/core/metrics.py`）+ `[AUDIT-LOSS]` 异常级日志（可告警），
调用本身继续放行（可用性取舍与 fail-open 限流一致，且写入披露）。回归：`tests/test_ss12_api_keys_audit.py`。

### 3.3 M1 — 认证失败计数无界增长 + 证书登录未落入严格 auth 限流桶
`app/core/scopes.py` 的 `_auth_failures` / `_cooldown_until` 由**未认证**输入驱动且无上限（内存 DoS 面）；
`app/core/security.py` 的严格 `auth` 桶只匹配 `/auth/login`，`/auth/login/cert`、`/auth/login/cert/challenge`、
`/auth/register` 走宽松 per-IP 桶。修复：两张表加 `MAX_TRACKED_AUTH_KEYS` 上限并在**写入之后**收口（见 §3.8），
桶匹配扩到四个认证入口。回归：`tests/test_ss12_api_keys_unit.py`（有界性 + 桶归属）。

### 3.4 M2 — 轮转已过期密钥会生成永不过期凭据
`app/api/api_keys.py` 轮转时直接沿用新有效期，忽略源密钥已过期的事实（过期密钥 → 有效凭据）。
修复：轮转继承源密钥的过期语义，已过期密钥轮转拒绝/继承过期时间。回归：`tests/test_ss12_api_keys_api.py`。

### 3.5 SM3 回退门可被绕过（审计 Merkle 叶的哈希诚实性）
`app/services/crypto_service.py:sm3_hash` 在 gmssl 缺失时无条件 `hashlib.sha256`，与 `CDS_SM3_FALLBACK_ALLOWED=false`

### 3.6 部署镜像未声明 `cryptography`（远程复验发现，本地不可见）

### 3.7 `tee_probe.py` 在 Python 3.12 上必崩（远程复验发现）
`deploy/cube-node/tee_probe.py` 默认参数 `exists=Path.exists` 是**未绑定方法**，却被按 `exists(str(c))` 调用：
CPython 3.12 抛 `AttributeError: 'str' object has no attribute 'stat'`（镜像内 100% 复现），3.14 容忍 str self 并返回结果，
因此本地全绿。触发条件是节点上存在 TEE 设备候选路径——正好是真实 TEE 节点路径。修复：默认改为 `os.path.exists`
（保持注入契约，测试替身不受影响）。回归：`tests/test_ss13_node_tee_probe.py` 14/14（3.12 镜像内）。

### 3.8 认证失败表上限 off-by-one（新增测试暴露）
`record_auth_failure` 原为"先裁剪后写入"，最坏可达 `limit + 1`。改为写后统一收口，界限对两张表都成立。

### 3.9 审计降级路径把请求会话打假死（新增测试暴露）
B2 原实现失败分支做整事务 `db.rollback()`，会 expire 会话内 `key`；下游**同步**的 scope 检查读
`subject.api_key.scopes` 时在无 greenlet 上下文重查 → `MissingGreenlet` → 审计存储抖动时 API Key 调用由"降级放行"变 500。
远程 py3.12 探针实测：`begin_nested`（SAVEPOINT）回滚**不会** expire 会话对象，`db.rollback()` 会。
修复：审计行由 SAVEPOINT 包裹，失败分支不再整事务回滚。回归：`tests/test_ss12_api_keys_audit.py` 6/6。
