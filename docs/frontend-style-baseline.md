## 2. 自适应断点阶梯（specs/ss-18-prototype-alignment.md §9 的摘要）

- 钉死像素的改动必须**同时给出该像素布局成立的宽度区间**；区间之外按阶梯退化，不许靠压缩内容硬塞。
- 阶梯：`1440 真值 → ≤1439 表单两列 → ≤1402 KPI 2×2 → ≤1200 分析卡堆叠 → ≤1023 侧栏 64/筛选折行 → ≤860 单列`。
- 每档必查三项：`docOverflow`＝0、**真出屏**＝0（滚动容器内的元素判为受控，不算出屏）、`crushed`（单元格/控件 `scrollWidth>clientWidth`）＝0。
- 反例入账：1024 档压字（事件流 69px 装 84–114px）、3-2 整页横溢 67–75px——都由「压列宽」而来，修法分别是卡内横滚与断点退列。
