# 密态沙箱系统 · 前端角色视图重新设计

> 核心原则修正:
> 1. 合约暂停/恢复在服务平台执行, 沙箱仅做合约状态校验
> 2. 数商通过沙箱开发上架数据产品 (质量预检/脱敏预览/策略测试)
> 3. 每个角色有独立的仪表盘和功能集
> 4. 数据类型完整覆盖: 结构化 / 半结构化 / 非结构化

---

## 数据类型体系

### 三大数据类型

| 类型 | 典型格式 | 存储形态 | 查询方式 | 脱敏粒度 |
|------|----------|----------|----------|----------|
| **结构化** | CSV, Parquet, 数据库表, Excel | 行列存储 (PostgreSQL/ClickHouse) | SQL | 列级/行级 |
| **半结构化** | JSON, XML, 日志文件, 传感器流 | 文档存储 (MinIO/对象存储) | JSONPath / Python | 字段级/嵌套路径 |
| **非结构化** | 图像(PNG/DICOM), 文档(PDF/Word), 音频(WAV/MP3), 视频(MP4) | 加密对象存储 (MinIO) | 推理/特征提取 | 内容级(人脸/NER/声纹) |

### 开发沙箱流程 (按数据类型分路径)

```
数商选择数据类型
  │
  ├── 结构化数据 ──────────────────────────────────────────────────
  │   ① 上传: CSV/Parquet 文件 或 配置数据库连接 (JDBC)
  │   ② Schema 自动推断: 字段名/类型/空值率/唯一值数
  │   ③ 敏感字段自动识别:
  │      - 正则匹配: 身份证/手机/银行卡/邮箱/地址
  │      - 值分布分析: 高基数+低重复 → 可能是标识符
  │      - 字段名语义: name/phone/id_card/email/address
  │   ④ 质量报告: 行数/列数/空值率/分布直方图/异常值
  │   ⑤ 脱敏预览:
  │      - 高敏列: 身份证→前3***后3, 手机→前3****后4
  │      - 普通列: 保留原值或泛化(年龄→年龄段)
  │      - 输出: 聚合统计 + 脱敏样本行
  │   ⑥ 策略配置: 允许SQL操作/输出行数/DP参数
  │   ⑦ 测试: 数商跑测试SQL验证脱敏效果
  │   ⑧ 发布: Schema + 质量报告 + 脱敏预览 → 目录
  │
  ├── 半结构化数据 ────────────────────────────────────────────────
  │   ① 上传: JSON/XML/日志文件 (支持大文件流式处理)
  │   ② 结构自动发现:
  │      - JSON: 递归解析键路径树 ($.user.name, $.user.phone)
  │      - XML: XPath 路径提取
  │      - 日志: 正则/JSON格式识别
  │   ③ 字段级敏感检测:
  │      - 键名匹配: name/phone/id/email/password/token
  │      - 值模式匹配: 手机号/身份证/邮箱正则
  │      - 嵌套深度标记: 标注敏感字段的完整路径
  │   ④ 质量报告: 记录数/嵌套深度/字段覆盖率/空值分布
  │   ⑤ 脱敏预览:
  │      - 保持JSON结构, 仅替换敏感字段值
  │      - 输出: 结构树 + 脱敏样本记录
  │   ⑥ 策略配置: 允许JSONPath查询/Python处理/输出格式
  │   ⑦ 测试: 数商跑测试JSONPath/Python验证
  │   ⑧ 发布: 结构树 + 质量报告 + 脱敏预览 → 目录
  │
  └── 非结构化数据 ────────────────────────────────────────────────
      ① 上传: 图像/文档/音视频文件
      ② 格式检测: MIME类型识别 (基于魔数)
      ③ 内容分析:
         - 图像: 人脸检测/DICOM标签/EXIF信息
         - 文档: OCR文字提取/NER实体识别/签名区域
         - 音频: ASR转录/说话人分离/声纹特征
         - 视频: 逐帧人脸检测/目标检测
      ④ 质量报告: 文件数/总大小/格式分布/内容摘要
      ⑤ 脱敏预览:
         - 图像: 人脸打码后的缩略图 + pHash
         - 文档: NER脱敏后的文本摘要
         - 音频: 匿名说话人统计 + 情绪分布
         - 视频: 行为事件标签 + 时间轴
      ⑥ 策略配置: 允许推理类型/输出格式/DP参数
      ⑦ 测试: 数商跑测试推理验证
      ⑧ 发布: 元数据 + 质量报告 + 脱敏预览 → 目录
```

### 买方沙箱控制台 (按数据类型分查询方式)

```
买方选择合约 → 创建会话 → 提交任务
  │
  ├── 结构化数据 → SQL 查询
  │   - 标准SQL语法 (SELECT/WHERE/GROUP BY/JOIN)
  │   - 支持聚合: COUNT/SUM/AVG/MIN/MAX/STDDEV
  │   - 限制: 禁止 SELECT *, 必须有 LIMIT
  │
  ├── 半结构化数据 → JSONPath + Python
  │   - JSONPath 查询: $.records[?(@.age>30)].name
  │   - Python 脚本: pandas + json 处理
  │   - 限制: 禁止网络调用, 禁止文件IO
  │
  └── 非结构化数据 → 推理任务
      - 图像分类/目标检测/特征提取
      - 文档OCR/NER/分类
      - 音频ASR/情绪分析/说话人识别
      - 视频行为分析/事件检测
      - 限制: 仅输出标签/统计/向量, 禁止输出原始内容
```

## 角色功能矩阵 (修正版)

### 数商 (Data Provider) - "我在沙箱中开发安全数据产品"

| 页面 | 功能 | 说明 |
|------|------|------|
| 我的工作台 | 产品概览卡片 | 已发布/草稿/被消费次数/收入统计 |
| 产品开发沙箱 | 按数据类型分路径的完整开发流程 | **核心**: 结构化/半结构化/非结构化各有专属流程 |
| 产品管理 | 编辑/版本/下架 | 产品生命周期管理 |
| 使用监控 | 买方访问记录/DP消耗排行/任务统计 | 了解产品被如何使用 |
| 我的密钥 | DEK 管理/密钥轮转/吊销 | 数据加密密钥生命周期 |

### 买方 (Data Buyer) - "我在沙箱中安全使用数据"

| 页面 | 功能 | 说明 |
|------|------|------|
| 我的工作台 | 活跃合约/会话/任务/DP预算 | 买方视角仪表盘 |
| 数据目录 | 搜索/筛选/查看质量报告/申请合约 | 支持按数据类型筛选 |
| 沙箱控制台 | 按数据类型分查询方式 | SQL / JSONPath+Python / 推理 |
| 任务历史 | 所有任务/结果/DP消耗/存证 | 历史追溯 |
| 我的证书 | SM2身份证书/会话密钥 | 身份凭证 |

### 运营方 (Operator) - "我保障数据空间安全运行"

| 页面 | 功能 | 说明 |
|------|------|------|
| 运营总览 | 全局健康/节点状态/吞吐量/告警 | 按数据类型统计任务分布 |
| 节点管理 | TEE/gVerdor/容器节点 | 集群管理 |
| 合约视览 | 只读查看所有合约状态 | 不可修改, 仅监督 |
| 审计中心 | 全量日志/Merkle存证/区块链验真 | 审计溯源 |
| 连接器 | 跨空间配置/身份互认/TLCP | 互联互通 |
| 用户管理 | 机构/用户/角色/证书 | 身份治理 |

### 监管方 (Regulator) - "我监督数据流通合规"

| 页面 | 功能 | 说明 |
|------|------|------|
| 合规总览 | 违规统计/DP消耗趋势/安全事件 | 按数据类型统计违规分布 |
| 审计查询 | 按时间/操作/合约/用户筛选 | 只读全量日志 |
| 存证验真 | 输入事件ID/哈希 → 验证链上存证 | 不可篡改验证 |
| 合规报告 | 导出合规报告/等保审计材料 | 报告生成 |
