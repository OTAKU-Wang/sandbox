## 3. 核心页面详细设计

### 3.1 运营概览 (Dashboard)

**数据卡片:**
- 活跃数据产品数 (按安全等级 L1/L2/L3 分色)
- 活跃合约数 / 即将到期合约数
- 活跃沙箱会话数 / 今日任务数
- DP 预算消耗率 (进度条)
- 节点状态 (SGX 节点数 / gVisor 节点数 / 离线节点数)

**图表:**
- 任务趋势图 (7天, 折线图)
- 策略拒绝率 (饼图)
- 安全等级分布 (柱状图)
- 跨空间会话数 (折线图)

**实时事件流:**
- 最近 10 条审计事件 (自动刷新)

### 3.2 数据产品管理

**注册表单 (Step Wizard):**

```
Step 1: 基本信息
  - 产品名称 (text)
  - 行业分类 (select: 政务·财税/医疗·健康/金融·风控/工业·IoT/其他)
  - 数据类型 (checkbox: 结构化/非结构化/半结构化)
  - 安全等级 (radio: L1-TEE标准/L2-软件增强/L3-最小化)
  - 数据量级 (number + unit)

Step 2: Schema 定义 (结构化数据)
  - 字段列表 (动态表格: 字段名/类型/敏感级别/描述)
  - 支持 CSV 导入自动识别

Step 3: 策略配置
  - 允许操作 (checkbox: aggregate/filter/join/statistical_model/inference)
  - 禁止操作 (checkbox: row_level_export/network_call/print/export)
  - 输出约束 (maxOutputRows/requireDP/epsilon/maxRuntimeSeconds)
  - 允许语言 (checkbox: python/sql/r)

Step 4: 上传与加密
  - 文件上传 (drag & drop, 支持大文件分片)
  - 加密进度条 (SM4-GCM)
  - 完整性校验 (SM3 hash 显示)

Step 5: 确认与发布
  - 预览摘要
  - 数字签名 (SM2 证书选择)
  - 发布至目录
```

### 3.3 数据目录检索

**搜索与筛选:**
- 关键词搜索 (全文)
- 行业分类筛选 (多选)
- 数据类型筛选 (结构化/非结构化/半结构化)
- 安全等级筛选 (L1/L2/L3)
- 数据空间筛选 (本空间/跨空间)

**产品卡片:**
```
┌─────────────────────────────────────────┐
│  🏥 某省医疗影像数据集 2024              │
│  医疗·健康 | 非结构化 | L1-TEE          │
│  50,000 文件 | 800 GB | CT 胸部         │
│  安全承诺: 人脸自动打码 + DICOM标签剥离    │
│  价格: ¥500/任务                         │
│  质量报告: 完整率 98% | 预览向量可用       │
│  [查看详情] [申请合约]                    │
└─────────────────────────────────────────┘
```

### 3.4 合约管理中心

**合约创建流程:**
```
选择产品 → 选择合约类型 → 配置条款 → 双方签名 → 激活
```

**合约类型:**
- 数据查询合约 (SQL)
- 模型训练合约 (Python/R)
- API 服务合约 (在线推理)
- 联合建模合约 (MPC)

**合约详情页:**
- 合约状态流转图 (状态机可视化)
- 条款摘要表
- DP 预算使用进度
- 签名验证状态 (SM2)
- 区块链存证链接 (FISCO BCOS tx hash)
- 操作按钮: 暂停/恢复/终止

### 3.5 沙箱控制台

**会话管理:**
- 创建会话 (选择合约 → 选择安全等级 → 获取证明报告)
- 会话列表 (状态/安全等级/到期时间/操作)

**任务提交:**
```
┌─────────────────────────────────────────────┐
│  提交计算任务                                 │
│                                             │
│  任务类型: ○ SQL  ○ Python  ○ 推理  ○ FL     │
│                                             │
│  代码编辑器:                                  │
│  ┌─────────────────────────────────────────┐ │
│  │ SELECT department, COUNT(*) as cnt      │ │
│  │ FROM employees                          │ │
│  │ WHERE age > 30                          │ │
│  │ GROUP BY department                     │ │
│  │ HAVING COUNT(*) > 10                    │ │
│  └─────────────────────────────────────────┘ │
│                                             │
│  [代码验证 ✓] [提交任务]                      │
│                                             │
│  实时状态: ● 执行中... (已运行 23s)           │
│  [取消任务]                                   │
└─────────────────────────────────────────────┘
```

**结果展示:**
- 表格视图 (JSON/CSV)
- 执行报告 (耗时/DP消耗/审查结果)
- SM2 签名验证状态
- 区块链存证链接
- 下载结果 (加密)

### 3.6 审计查询台

**筛选条件:**
- 时间范围 (日期选择器)
- 操作类型 (多选)
- 策略决策 (allow/deny)
- 安全等级 (L1/L2/L3)
- 用户/会话/合约 ID

**日志表格:**
| 时间 | 事件ID | 用户 | 操作 | 资源 | 决策 | DP消耗 | 安全等级 | 存证 |

**存证验真:**
- 输入事件 ID 或 Merkle 根
- 查询区块链存证
- 显示 Merkle 证明路径
- 验证结果 (✓ 已存证 / ✗ 未找到)

### 3.7 监控运维

**节点状态面板:**
```
┌─────────────────────────────────────────────┐
│  节点集群                                    │
│                                             │
│  🟢 sgx-node-1   L1  EPC: 45/64GB  负载: 30%│
│  🟢 sgx-node-2   L1  EPC: 20/64GB  负载: 60%│
│  🟡 gvisor-node-1 L2  MEM: 80/128GB 负载: 75%│
│  🟢 docker-node-1 L3  MEM: 40/64GB  负载: 50%│
│  🔴 offline-node  L1  离线 - 熔断器: OPEN    │
└─────────────────────────────────────────────┘
```

**实时指标:**
- 任务吞吐量 (tasks/min)
- 平均执行时长
- 策略拒绝率
- DP 预算消耗率
- 输出审查拦截次数
