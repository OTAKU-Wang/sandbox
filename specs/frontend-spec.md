# 密态沙箱系统 · 前端功能规格说明书（Frontend Spec）

> 版本：v2.0 (开发者工作台闭环与唯 CubeSandbox 架构版)  
> 对齐：product-spec v2.0 + data-sandbox-developer-portal-prd v2.0 + prototype-v3.html  
> 受众：前端工程师、UX 设计师、产品经理、AI 协同 Agent  
> 核心原则：**唯 CubeSandbox MicroVM 运行时**（彻底下线 Bubblewrap 进程隔离与 Kubernetes 容器沙箱），采用**双模式工作台体系**。

---

## 1. 架构模式：双模式工作台 (Dual-Workspace)

平台采用双工作台架构，彻底实现开发者日常研发与管理员全栈运维的解耦：
1. **开发者工作台（Developer Workspace · 默认主站）**：
   - 目标角色：数据购买方、算法/模型工程师（如沈阳数据中心R/张伟）。
   - 采用高度聚焦的 **4+2 菜单架构**：
     - `首页`（平台总览）：运行大盘、沙箱内存双进度条、7天趋势、最新结果集。
     - `我的开发`：任务列表、新增任务、Web IDE 在线调试沙箱、任务详情、固化发布、运行追踪。
     - `我的结果集`：文件结果集资产（脱敏预览/下载）、OpenAPI 导出与监控、Webhook 结果推送。
     - `安全管理`：操作日志全生命周期留存与区块链 Merkle 验真。
     - *左下角常驻*：开发指引文档、环境与配额说明。
2. **空间管理后台（Space Admin Console · 管理态）**：
   - 目标角色：平台运维人员、合规审计安全官（`admin` / `operator`）。
   - 顶部提供一键切换入口，承载 CubeSandbox 物理节点拓扑纳管、CA 证书管理、KMS/MPC 分布式分片、跨空间联邦连接器配置等底层平台能力。
   - **已下线/移除**：历史遗留的 Kubernetes Pod 运营模块 (`/ops/*`) 与 CapabilityMatrix 多等级混杂对比页面已全面废弃。

## 3. 核心页面详细设计

### 3.1 运营概览 (Dashboard)

**数据卡片:**
- 活跃数据产品数 (按安全等级 L1/L2/L3 分色)
- 活跃合约数 / 即将到期合约数
- 活跃沙箱会话数 / 今日任务数
- DP 预算消耗率 (进度条)
- 节点状态 (SGX 节点数 / gVisor 节点数 / 离线节点数)

**图表:**
- 任务趋势图 (7天, 折线图)
- 策略拒绝率 (饼图)
- 安全等级分布 (柱状图)
- 跨空间会话数 (折线图)

**实时事件流:**
- 最近 10 条审计事件 (自动刷新)

### 3.2 数据产品管理

**注册表单 (Step Wizard):**

```
Step 1: 基本信息
  - 产品名称 (text)
  - 行业分类 (select: 政务·财税/医疗·健康/金融·风控/工业·IoT/其他)
  - 数据类型 (checkbox: 结构化/非结构化/半结构化)
  - 安全等级 (radio: L1-TEE标准/L2-软件增强/L3-最小化)
  - 数据量级 (number + unit)

Step 2: Schema 定义 (结构化数据)
  - 字段列表 (动态表格: 字段名/类型/敏感级别/描述)
  - 支持 CSV 导入自动识别

Step 3: 策略配置
  - 允许操作 (checkbox: aggregate/filter/join/statistical_model/inference)
  - 禁止操作 (checkbox: row_level_export/network_call/print/export)
  - 输出约束 (maxOutputRows/requireDP/epsilon/maxRuntimeSeconds)
  - 允许语言 (checkbox: python/sql/r)

Step 4: 上传与加密
  - 文件上传 (drag & drop, 支持大文件分片)
  - 加密进度条 (SM4-GCM)
  - 完整性校验 (SM3 hash 显示)

Step 5: 确认与发布
  - 预览摘要
  - 数字签名 (SM2 证书选择)
  - 发布至目录
```

### 3.4 合约管理中心

**合约创建流程:**
```
选择产品 → 选择合约类型 → 配置条款 → 双方签名 → 激活
```

**合约类型:**
- 数据查询合约 (SQL)
- 模型训练合约 (Python/R)
- API 服务合约 (在线推理)
- 联合建模合约 (MPC)

**合约详情页:**
- 合约状态流转图 (状态机可视化)
- 条款摘要表
- DP 预算使用进度
- 签名验证状态 (SM2)
- 区块链存证链接 (FISCO BCOS tx hash)
- 操作按钮: 暂停/恢复/终止

### 3.5 沙箱控制台

**会话管理:**
- 创建会话 (选择合约 → 选择安全等级 → 获取证明报告)
- 会话列表 (状态/安全等级/到期时间/操作)

**任务提交:**
```
┌─────────────────────────────────────────────┐
│  提交计算任务                                 │
│                                             │
│  任务类型: ○ SQL  ○ Python  ○ 推理  ○ FL     │
│                                             │
│  代码编辑器:                                  │
│  ┌─────────────────────────────────────────┐ │
│  │ SELECT department, COUNT(*) as cnt      │ │
│  │ FROM employees                          │ │

│  │ HAVING COUNT(*) > 10                    │ │
│  └─────────────────────────────────────────┘ │
│                                             │
│  [代码验证 ✓] [提交任务]                      │
│                                             │
│  实时状态: ● 执行中... (已运行 23s)           │
│  [取消任务]                                   │
└─────────────────────────────────────────────┘
```

**结果展示:**
- 表格视图 (JSON/CSV)
- 执行报告 (耗时/DP消耗/审查结果)
- SM2 签名验证状态
- 区块链存证链接
- 下载结果 (加密)

### 3.6 审计查询台

**筛选条件:**
- 时间范围 (日期选择器)
- 操作类型 (多选)
- 策略决策 (allow/deny)
- 安全等级 (L1/L2/L3)
- 用户/会话/合约 ID

**日志表格:**
| 时间 | 事件ID | 用户 | 操作 | 资源 | 决策 | DP消耗 | 安全等级 | 存证 |

**存证验真:**
- 输入事件 ID 或 Merkle 根
- 查询区块链存证
- 显示 Merkle 证明路径
- 验证结果 (✓ 已存证 / ✗ 未找到)
